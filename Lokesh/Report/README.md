# Lokesh report

This folder contains the NeurIPS-style technical report for the `Lokesh/` experiments.

- `draft/main.tex`: LaTeX source.
- `draft/neurips_2025.sty`: unmodified copy of the NeurIPS 2025 style file supplied in the parent `cv_project/` directory.
- `draft/figs/`: selected plots copied from the saved result artifacts.
- `draft/main.pdf`: compiled report.
- `../Final_Report.pdf`: convenient copy at the root of the `Lokesh/` folder.

Build from `Lokesh/` with:

```bash
tectonic Report/draft/main.tex
```

The NeurIPS file is used for typography and layout only. The notice identifies this as an IIT Jodhpur technical report; it does not imply NeurIPS submission, review, or acceptance.
