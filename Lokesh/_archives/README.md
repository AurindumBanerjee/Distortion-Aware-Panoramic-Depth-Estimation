# Lokesh experiment archive

This directory preserves earlier experiment artifacts and bundles without deleting the source results.

- `01_code.zip`: archived code snapshot.
- `02_notebooks.zip`: notebook snapshot.
- `03a_*` / `03b_*`: MiDaS DPT-Hybrid synthetic run and qualitative artifacts.
- `04a_*` / `04b_*`: MiDaS Swin2-Tiny synthetic run and qualitative artifacts.
- `05a_*` / `05b_*`: pre-seam-prior v1 run and qualitative artifacts.
- `root_debug_samples_20261110/`: loose per-panorama debug predictions and visualizations moved out of the `Lokesh/` root during final cleanup; no source data was deleted.
